# Autonomous Indoor Delivery Robot

This project implements an autonomous indoor delivery robot capable of navigating indoor environments, detecting objects, and delivering items to target locations. It integrates computer vision, motion planning, and mobile robot control within a modular robotics pipeline.

---

## 📄 Project Notebook  
You can view the full implementation here:  
**AutonomousIndoorDeliveryRobot_CP2.ipynb**

---

## 🚀 Features

### 🔍 Perception
- RGB-D sensing for 3D environment understanding  
- Object detection and pose estimation  
- Vision-based state updates integrated into the robot autonomy stack  

### 🤖 Navigation & Motion Planning
- Autonomous path planning with obstacle avoidance  
- Real-time trajectory generation  
- Closed-loop correction for dynamic environments  

### 🧠 Autonomy & Control
- Behavior-based decision system  
- Delivery-task execution pipeline  
- Robust handling of environment changes and navigation failures  

---

## 🛠️ System Architecture
- Modular ROS-based design  
- Simulation & testing loop  
- Parameter tuning for controller stability and delivery precision
